# My Cloud Service

A cloud storage app built with HTML, CSS, JavaScript, and Supabase.

## Setup

1. Create a Supabase project and a storage bucket named `files`.
2. Run `supabase_setup.sql` in Supabase.
3. Set the Supabase URL and publishable key in `script.js`.
4. Serve this folder over HTTP.

Live site: https://bestboyssd.github.io/MyCloudService/
